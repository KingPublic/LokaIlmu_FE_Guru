# 📖 Overview

**LokaIlmu** is a mobile application developed to support teachers in improving their professional competencies through accessible digital learning.

The application provides online training, mentor matching, discussion forums, digital learning resources, and learning progress tracking within a single platform.

Unlike a prototype-only project, **LokaIlmu was designed and implemented as a functional Android application**, following a complete Software Engineering lifecycle—from requirement analysis and system design to backend API development and mobile implementation.

# 🏗 System Architecture

```text
Flutter Mobile Application
            │
       RESTful API
            │
     Laravel Backend
            │
      MySQL Database
```

The application follows a **Client–Server Architecture**, with Laravel providing RESTful API services and Flutter consuming the APIs using the **BLoC architecture** for state management.
